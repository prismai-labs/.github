# Prism brand assets

These files are the editable vector sources for the Prism AI Labs organization identity.

- prism-mark.svg — square symbol for avatars and compact placements.
- prism-logo-dark.svg — wordmark for dark surfaces.
- prism-logo-light.svg — wordmark for light surfaces.
- prism-banner-dark.svg — 1440 × 420 dark GitHub/profile banner.
- prism-banner-light.svg — 1440 × 420 light GitHub/profile banner.
- prism-social-preview.svg — 1200 × 630 social-preview source artwork.

Use the corresponding theme variant. Keep the symbol proportional, preserve clear space, and retain the text labels. Do not add unrelated creator, store, or community links to Prism assets.

See ../BRAND.md for color, typography, clear-space, accessibility, and legal guidance.
