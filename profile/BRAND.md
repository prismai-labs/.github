# Prism AI Labs visual identity

## Core idea

The symbol is an original faceted prism: a geometric frame with a central aperture and six colored planes. It is intended to suggest focus, clarity, and multiple perspectives without borrowing a stock icon or another company's mark.

## Palette

| Role | Color |
| --- | --- |

| Primary violet | `#9B5CFF` |

- [Square prism symbol](assets/prism-mark.svg)

The square symbol is the preferred avatar/app icon. Use the dark wordmark on dark surfaces and the light version on light surfaces. Preserve clear space around the mark and do not stretch, recolor, or add effects to the supplied artwork.

## Typography

The SVG wordmarks use system sans-serif fallbacks (Inter, Segoe UI, Arial). No third-party font file is bundled.

## Asset and legal notes

The vector geometry and lockups were created specifically for this Prism AI Labs identity and use no external icon packs, stock artwork, or embedded font assets. The generated PNG source has not been compared against every registered or unregistered logo. This is an originality statement about the supplied artwork, not a trademark clearance opinion. The PRISM / Prism AI name has separate unresolved trademark risk; complete clearance requires qualified counsel.
