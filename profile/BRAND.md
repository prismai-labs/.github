# Prism AI Labs visual identity

## Core idea

The symbol is an original faceted prism: a geometric frame with a central aperture and six colored planes. It is intended to suggest focus, clarity, and multiple perspectives. The banners extend that same geometry into a restrained visual system: quiet grid detail, soft violet/cyan light, generous negative space, and clear typography.

## Brand voice and positioning

Primary line: **Research. Writing. Developer tools.**

Supporting description: **Focused software for clearer thinking and practical AI workflows.**

Use these lines consistently in organization-level material. Product-specific pages should describe the relevant product and not imply that experimental tools are mature hosted services.

## Typography

Use system sans-serif fallbacks: Inter, ui-sans-serif, system-ui, Segoe UI, Arial. No third-party font file is bundled. Preserve the supplied SVG text as live text so the assets stay searchable and editable.

## Layout and clear space

- Keep the prism mark proportional; never stretch it or change its facet geometry.
- Keep at least 8% clear space around the mark when it is used by itself.
- The profile banners use a left-aligned text block and a right-aligned symbol; do not crop either element.
- Keep the banner title and supporting copy in the same hierarchy. Do not add extra slogans or product claims without updating this guide.
- The banners are deliberately square-cornered so they sit cleanly inside GitHub layouts and can be cropped by platforms without revealing a contrasting corner.

## Theme and background usage

- Use the dark banner on dark surfaces and the light banner on light surfaces.
- The organization README uses GitHub's dark/light theme image suffixes so readers receive the matching banner.
- Use the square symbol where a platform cannot display a wide banner.
- Do not place the dark wordmark on dark backgrounds or the light wordmark on light backgrounds.

## Accessibility and rendering

- Keep meaningful alternative text on every embedded banner.
- Do not rely on color alone to distinguish project labels; the labels also contain text.
- Avoid shrinking the banner below its intended display width where the title or supporting line becomes unreadable.
- Visual review was performed at the supplied render sizes. A formal WCAG contrast or trademark clearance certification has not been performed.
