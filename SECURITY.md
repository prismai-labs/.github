# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in any **Prism AI Labs** repository, please do **not** open a public issue with exploit details.

Instead, report the issue privately to the maintainers (`@akahn30`) with:
- Affected repository and version/commit
- A clear description of the vulnerability and reproduction steps
- Potential impact and suggested remediation (if available)

## Scope

This policy covers repositories under `prismai-labs`, including `prism-ai`, `prism-mcp-server`, `prism-sdk`, and `prism-docs`.
