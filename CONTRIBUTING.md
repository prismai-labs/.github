# Contributing to Prism AI Labs

Thanks for your interest in contributing to **Prism AI Labs** (`prismai-labs`).

## Development Workflow

1. Fork the relevant repository or create a feature branch from `main` (for example, `feat/mcp-tool` or `fix/client-retry`).
2. Install dependencies with `npm install`.
3. Run linting, tests, and builds locally before opening a pull request:
   - `npm run lint`
   - `npm test`
   - `npm run build`
4. Keep changes focused, typed in TypeScript, and well-documented.

## Pull Requests

- Reference related issues in your PR description.
- Ensure CI checks (`lint`, `test`, `build`) pass.
- Request review from repository maintainers (`@akahn30`).
